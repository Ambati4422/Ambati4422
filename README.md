## 👋 About Me

I'm a **Data Analyst at iLogitek Business Solutions, Bengaluru**, focused on turning raw data into clean, reliable dashboards that help teams make better decisions.

- 📊 Build interactive dashboards in **Power BI** and **Tableau**
- 🗄️ Use **SQL** for extraction, transformation and analysis
- 🐍 Use **Python (Pandas, NumPy)** for cleaning, analysis and visualization
- 🧹 Care about data quality: validation, cleaning and accurate reporting
- 🎯 Currently learning: **Advanced DAX · Advanced SQL · BigQuery**
